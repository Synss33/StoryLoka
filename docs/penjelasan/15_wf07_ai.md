# WF-07 — AI / LLM (Proxy Gemini)

> **Fitur:** F-11 (AI + LLM) · **Layar:** SCR-05 (chat), SCR-06 (kartu AI: Ringkas + Tanya AI) · **Alur:** workflow §3.5 · **Test:** TC-24, TC-25 (`ai_test`)

## 1. Alur fitur (workflow §3.5 → kode)

```
Pengguna kirim prompt (+ konteks buku dari SCR-06 lewat ?book=<id>)
→ POST /ai/chat (token sesi Bearer)
→ backend memanggil Gemini (API key HANYA di .env server)
→ balasan → tampil + label "Dihasilkan AI"
→ error/timeout/kuota → pesan + Coba Lagi
→ offline → input dinonaktifkan + banner (TC-25)
```

Ringkasan buku: **baca dulu `ai_cache`** (key `summary:<bookId>`) → kosong? baru panggil backend → simpan hasil (K-38).

## 2. Klien (`lib/`)

**`core/network/ai_service.dart:36`** — *"Klien proxy AI: `POST /ai/*` ke backend, API key tetap di server. Setiap kegagalan dipetakan ke [AiFailure] agar SCR-05/06 bisa menampilkan offline / kuota / coba-lagi dengan pesan yang jelas."*

| Enum `AiFailure` | Komentar | Sumber |
|---|---|---|
| `offline` | "Jaringan/timeout klien — dianggap offline" (`:8`) | gagal jaringan |
| `quota` | "Kuota Gemini habis (HTTP 429)" (`:11`) | `error.code` backend |
| `disabled` | "API key belum diatur di server (HTTP 503 `AI_DISABLED`)" (`:14`) | K-36 |
| `error` | "galat lain (timeout upstream…) — bisa dicoba lagi" (`:17`) | 502/504 |

Pemetaan `ApiResponse` → `AiResult` di `:94`; token sesi dibaca di `:142`.

**`core/db/ai_cache_repository.dart:6`** — *"hasil ringkasan AI per buku disimpan agar tetap tampil saat offline ('hasil ringkasan di-cache lokal')"*; `:13` upsert per key; `:31` baca (`null` bila belum pernah).

## 3. Backend (`backend/src/…`)

**`services/ai.service.js:3`** — ketentuan proxy:
- API key **HANYA** di `.env` server — tidak pernah dikirim ke klien;
- prompt sistem membatasi jawaban ke **topik buku + bahasa Indonesia**;
- kegagalan dipetakan ke kode jelas agar klien bisa menampilkan "kuota habis" / "coba lagi";
- `AI_MOCK=1` → balasan tetap tanpa jaringan (test deterministik);
- tanpa API key → `AI_DISABLED` 503 (**aplikasi tetap jalan** — K-18).

`SYSTEM_PROMPT` (`:15`): *"Kamu adalah 'Storyloka AI'… Jawab HANYA seputar buku dan bacaan… maksimal ±120 kata, format teks biasa."*

| Endpoint | Handler | Kontrak (komentar `ai.controller.js`) |
|---|---|---|
| `POST /ai/chat` | `:28` | body `{ message, history?, context? }` → `{ reply, serverTime }` |
| `POST /ai/summarize` | `:48` | body `{ title, author, synopsis?, notes? }` → `{ summary, serverTime }` |
| `POST /ai/recommend` | `:70` | body `{ books: [{ title, author?, genre?, rating? }] }` → `{ recommendations, serverTime }` |

Galat berkode (`ai.controller.js:8`): 429 kuota · 504 timeout upstream · 503 layanan mati · 502 gagal. Konfigurasi model/timeout: `config/env.js` (`gemini-2.5-flash`, `AI_TIMEOUT_MS` 20 dtk, `GEMINI_API_KEY`).
